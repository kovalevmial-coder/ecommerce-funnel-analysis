Воронка конверсии и продуктовая аналитика

**Цель:** Найти «узкое место» в пользовательском пути и предложить улучшения.

**Демонстрируемые навыки:**
- Построение воронки конверсии (последовательные события).
- Расчет конверсии каждого этапа и общей конверсии.
- Сегментация воронки по устройствам, каналам, гео.
- Проверка гипотез о различиях конверсии между сегментами (хи-квадрат, z-тест).
- Визуализация воронки (bar chart, funnel chart).

**Рекомендуемый датасет:**
- **E-commerce Events History** (Kaggle) — события пользователей (view, cart, purchase) на маркетплейсе.  
  *Ссылка:* `https://www.kaggle.com/datasets/mkechinov/ecommerce-events-history-in-cosmetics-shop`  
- Альтернатива: **Olist** — можно восстановить воронку из статусов заказа (`order_status`).

**Что сделать:**
1. Определить этапы воронки (например: `view` → `cart` → `purchase`).
2. Рассчитать конверсию на каждом шаге и общую.
3. Разбить воронку по сегментам (например, по типу устройства) и сравнить.
4. Проверить статистическую значимость различий с помощью хи-квадрат.
5. Предложить гипотезы для улучшения (A/B-тест на следующем этапе).

**Инсайт для резюме:** в README обязательно опишите, *какое бизнес-решение* вы предлагаете на основе анализа.
